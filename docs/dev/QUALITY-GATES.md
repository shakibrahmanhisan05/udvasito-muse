# UDVASITO — Quality Gates for P0 and P1

**Workstream C (independent QA).** Every gate is pass/fail, tied to a source document and section, with the exact verification and the evidence that counts as passing. A gate is **not** passed by "it worked on my phone once" — it passes when the listed evidence exists and can be re-run by someone else.

Conventions: `npm run check` = `tsc --noEmit && eslint . && vitest run` (CLAUDE.md §4). Phase DoD in `roadmap.md` §2.3 applies to **every** phase on top of the phase-specific DoD.
