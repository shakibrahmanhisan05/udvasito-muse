# Team content (roadmap §5.4)

Markdown written by the team lives here: `legal/privacy.<lang>.md`,
`legal/terms.<lang>.md`, `<lang>/learn.md`, `<lang>/dengue.md`, each starting
with the frontmatter block from roadmap §5.4. Run `npm run content:build` to
generate `generated/*.json` for CMP-Markdown.

The legal texts are DEP-02 (draft pilot notice due Day 4, final after the
Day-12 law review) — they are intentionally **not** pre-written by the coding
agent, because consent copy is a team/legal decision (CLAUDE.md §3: never
invent copy). The welcome screen's consent gate (G3) already works against
`settings.consentVersion`.
